## Packages on npm

| Package | Purpose | Install |
| ------- | ------- | ------- |
| [`@chuo-gpa/core`](https://www.npmjs.com/package/@chuo-gpa/core) | Main engine: GPA, CGPA, classification, grade conversion | `npm i @chuo-gpa/core` |
| [`@chuo-gpa/udsm`](https://www.npmjs.com/package/@chuo-gpa/udsm) | Pre-bound UDSM helpers | `npm i @chuo-gpa/udsm` |
| [`@chuo-gpa/udom`](https://www.npmjs.com/package/@chuo-gpa/udom) | Pre-bound UDOM helpers | `npm i @chuo-gpa/udom` |
| [`@chuo-gpa/iaa`](https://www.npmjs.com/package/@chuo-gpa/iaa) | Pre-bound IAA helpers | `npm i @chuo-gpa/iaa` |
| [`@chuo-gpa/types`](https://www.npmjs.com/package/@chuo-gpa/types) | Shared TypeScript types | `npm i @chuo-gpa/types` |
| [`@chuo-gpa/university-rules`](https://www.npmjs.com/package/@chuo-gpa/university-rules) | Rules registry & custom universities | `npm i @chuo-gpa/university-rules` |
| [`@chuo-gpa/utils`](https://www.npmjs.com/package/@chuo-gpa/utils) | Shared utilities | `npm i @chuo-gpa/utils` |

All packages are **public** and free on npm under the MIT license.
